# 💖 Happy Birthday, Beautiful · Romantic Cinematic Celebration

A romantic, cinematic birthday surprise website.

## ✨ Features
- 🎬 **Cinematic Widescreen Theater Frame** with ambient lighting and dynamic color bleed from each photo
- 📸 **10 Memories with 10 Unique Animations** (Golden Bloom, Ken Burns Zoom, Silk Slide, 3D Horizon Tilt, Celestial Float, Prism Unveil, Cinema Shutter, Golden Hour Swirl, Ethereal Mirage, Twilight Crescendo)
- 🎵 **Background Music** with soft-start chorus and interactive soundwave controls
- 📱 **Mobile Responsive** with touch swipe navigation (left/right swipe)
- 💌 **Grand Finale Letter** with interactive pulsing heart and celebration effects
